# Diesel Price News Website - Latvia

This is an MVP (Minimum Viable Product) for a diesel price news website in Latvia, built with Astro v5, Tailwind CSS v4, DaisyUI v5, Chart.js, and Alpine.js.

## Features

*   **Homepage:** Displays current diesel price, daily price change, and last update timestamp.
*   **Price History:** A 7-day line chart of diesel prices using Chart.js.
*   **News Feed:** A list of recent price-related news articles.
*   **About Page:** Information about data sources and contact details.
*   **Bilingual Support:** All content available in Latvian (LV) and English (EN) with a language switcher.
*   **Responsive Design:** Mobile-first approach using Tailwind CSS and DaisyUI.
*   **Static Site Generation:** Built with Astro for fast performance and SEO.

## Tech Stack

*   **Framework**: Astro v5
*   **Styling**: Tailwind CSS v4, DaisyUI v5
*   **Charts**: Chart.js
*   **Interactivity**: Alpine.js
*   **Data**: Mock JSON files (`src/data/prices.json`, `src/data/news.json`)
